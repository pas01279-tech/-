# Конструктор педагогічного запиту до ШІ

Інтерактивний HTML-ресурс для вчителів технологій. Працює без збірки й зовнішніх бібліотек.

## Розміщення на GitHub Pages
1. Створіть новий репозиторій на GitHub.
2. Розпакуйте архів і завантажте `index.html` у корінь репозиторію (можна також додати README.md).
3. Відкрийте **Settings → Pages**.
4. У **Build and deployment** оберіть **Deploy from a branch**, гілку **main** і папку **/(root)**, натисніть **Save**.
5. Після публікації відкрийте посилання на сайт, яке покаже GitHub Pages.
